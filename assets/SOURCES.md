# Visual sources

Technology logo paths are copied from the portfolio’s locally bundled Simple Icons
assets (package version 16.34.0). The colored marks are rendered as transparent PNGs; SVG sources are retained.
Rust, Linux and Pandas use lighter colors for visibility in both GitHub themes. The CC0 license is included in
[technology/LICENSE.md](./technology/LICENSE.md). Brand names and trademarks belong
to their respective owners.

School PNGs preserve the supplied logo colors and proportions, without degree
captions. ENS Paris-Saclay uses a light blue backing; École des Ponts is transparent, with
a light monochrome version selected for dark mode.
They identify education, rather than sponsorship or endorsement.

- ENS Paris-Saclay: [official website asset](https://ens-paris-saclay.fr/sites/default/files/ENSPS_UPSAY_logo_couleur_2.png).
- École des Ponts: [official graphic-guidelines asset](https://ecoledesponts.fr/sites/default/files/pages/Ecole/Logo-ENPC-IP-RVB.png).

Project screenshots are copied from the portfolio’s display assets. Nova uses a
sample profile with simulated backend/model state; Supply Chain uses synthetic
preview data; Billiards Saloon is a native desktop capture. Their captions appear
in the profile README.

The banner is a custom SVG illustration. All display assets are local and do not
require the portfolio reference directory or a logo CDN.
